鱼眼拉伸效果

拉伸效果就是整个图形似乎沿着某些方向拉伸。这通过操控UV偏移可以来实现。通过使每个点上的UV沿着中心圆向径外偏移一点可以实现这样的效果

// 鱼眼效果 uv叠加一个 径向的向外偏移 距离越远 偏移越大
vec2 warp(vec2 uv){
	vec2 center_uv = 2.0*uv-1.0;
	float squared_dist = dot(center_uv,center_uv); // x^2+y^2
	// uv 往径向偏移
	squared_dist = pow(squared_dist,warp_exp);
	return uv+center_uv*squared_dist*warp_amount;
}

这个UV添加偏移产生效果的流程很有意思，其实简单来看就是计算每个点到中心距离，这个形成一个场，然后调整大小进行叠加。这种UV扰动感觉可以产生很多效果。

扫描线

扫描线相对来说就很简单了。在扭曲后的UV上叠加一个明暗交替的线即可，这个可以通过三角函数的周期性比较好的实现

vec3 ScanLines(vec2 uv)
{
	float scan_color = sin(uv.y*scan_line_num*PI+TIME*scan_line_speed)*0.5+0.5;
	scan_color = scan_color*scan_line_intensity+(1.0-scan_line_intensity);
	return vec3(scan_color);
}

通过放缩UV坐标域增加明暗条纹数量。通过TIME来实现缓慢移动效果。通过调整sin值域大小来加强明暗对比感。这里直接用了三角函数的原值可以通过一下缩放来调整这种效果，例如教程里面的

scan_color = (scan_color*0.5+0.5)*0.9+0.1
scan_color = pow(scan_color,scanline_opacity);

暗角效果

暗角效果就是越往角落里面越暗。这个跟扭曲函数中计算距离相似。计算一个压暗数值，叠加到最后采样上面即可。

vec3 vignette(vec2 uv){
	vec2 center_uv = 2.0*uv-1.0;
    float squared_dist = dot(center_uv,center_uv); // x^2+y^2
    return 1.0-square_dist*vignette_strength;
}
