11-画面放大

本文主要实现类似放大镜的效果，以及模糊的效果。

这是一个基于Canvas着色器的直接应用。为了要做放大镜效果，就需要知道当前Texture后的图像。通过如下接口可以直接把Texture后方图像渲染在当前sprite2D上。

uniform sampler2D screen_texture : hint_screen_texture;

void fragment(){
    COLOR = texture(screen_texture,SCREEN_UV);
}

其中SCREEN_UV就是当前片元所在整个截屏材质的UV位置。要操作放大效果只要修改该数值即可。

要做放大效果，实际上就是当前采样的UV矩形略小于其原始值。并且要进行中心缩放。这就需要将图片的中心点传递到片元着色器。这个就需要通过矩阵变换操作来得到，对于图片中心来说，相当于其局部坐标的$(0,0)$点。所以可以通过如下方式传递中心位置：

varying vec2 screen_center_pos;

void vertex() {
	screen_center_pos = (CANVAS_MATRIX*MODEL_MATRIX*vec4(0,0,0,1)).xy;
}

然后每个片元采样的位置根据中心位置扩展缩放即可

void fragment() {
	vec2 center_uv = screen_center_pos*SCREEN_PIXEL_SIZE;
	
	vec2 scale_screen_uv = center_uv+(SCREEN_UV-center_uv)*scale_ratio;
	// 也可以用 插值的方式来理解 这个放射插值
	COLOR.rgb = texture(screen_texture,scale_screen_uv).rgb;
}

教程第二部分是模糊，这里模糊是通过mipmap的形式来实现的。mipmap会采用如下两种方式生成一系列尺寸更小的贴图

  • 在纹理最近的4个像素之间进行线性插值
  • 在最近的两个mipmap层级之间进行线性插值

因为贴图小了，相邻被被插值，观感上来看，就是图像变模糊了。要使用mipmap可以如下修改采样函数即可

uniform sampler2D screen_texture : hint_screen_texture,filter_linear_mipmap;
uniform float blur : hint_range(0.0,2.0);

void fragment() {
    //...
    COLOR.rgb = textureLod(screen_texture,scale_screen_uv,blur).rgb;
}
